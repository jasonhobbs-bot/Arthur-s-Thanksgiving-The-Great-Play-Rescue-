ARTHUR'S THANKSGIVING — LITTLE STAGE ADVENTURE
Pre-K, Kindergarten & First Grade | iPad + GitHub Pages

START PLAYING
1. Unzip the download. The game is index.html.
2. On your Mac, double-click index.html to test in Chrome or Safari.
3. On GitHub, create or open a PUBLIC repository.
4. Upload index.html to the ROOT of the repository.
5. Go to Settings > Pages > Build and deployment > Deploy from a branch.
6. Select main, /(root), then Save.
7. Open the GitHub Pages link in Safari on the iPads.
   GitHub Pages on a public repo is free on GitHub's Free plan.

CLASSROOM GAME
- Select Pre-K, Kindergarten, or First Grade on the first screen.
- Story: Arthur needs help with the Thanksgiving school play because nobody
  wants to be the turkey.
- Activities: The Big Problem (read-aloud story), Turkey Hunt (four rounds),
  Coloring Studio (three original finger-colorable pages), Rehearsal Dance
  (four watch-and-repeat patterns), Prop Catch (three arcade rounds),
  and The Big Show (four stage-decoration rounds).
- Coloring: choose 15 colors, color by touch, place stickers, undo/redo,
  and Save Picture to download a PNG. Earn a Costume Designer badge.
- No accounts, logins, ads, online assets, subscriptions, or student names.
- Progress auto-saves to the same browser/device in local storage.
- Playtime varies widely. Suggested for one classroom lesson with the
  book read-aloud and extended creative coloring (roughly 25-30 minutes);
  this timing has not been validated with a student group.
- Works best in Safari or Chrome on recent iPads; landscape gives more room.
- To update a published game, replace the root index.html and refresh Safari.

TECHNICAL NOTES
- The HTML is completely self-contained: no libraries or CDNs.
- Optional synthesized read-aloud needs an available speech voice and
  a user tap before it can speak, depending on browser settings.
- PNG exports depend on the browser's download permissions; on iPad,
  check Files > Downloads, or use the Share sheet / screenshot if needed.
- This is a fan-made classroom learning activity with original illustrations
  inspired by the book Arthur's Thanksgiving. It is not an official Arthur
  product and does not reproduce the published book's text or illustrations.
